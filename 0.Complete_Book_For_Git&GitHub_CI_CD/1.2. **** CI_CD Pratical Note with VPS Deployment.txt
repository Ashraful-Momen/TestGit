3.0  LOCAL REPO SETUP  -- git clone + git credentials  (one-time)
----------------------------------------------------------------
  STEP A: GitHub e repo banao (browser)
    1. https://github.com/new  e jaao
    2. Repository name: test_ci_cd
    3. Public/Private bacho, "Add a README" tick dao
    4. "Create repository" click

  STEP B: Git identity set koro (prothom bar, one-time)
    git config --global user.name "Ashraful"
    git config --global user.email "your_github_email@example.com"
    #  --> ei name/email commit history te dekha jabe
    # verify:
    git config --global --list

  STEP C: Repo clone koro (local PC te)
    cd /path/to/Practise_Code/CI_CD
    git clone https://github.com/ashrafulunisoft/test_ci_cd.git
    cd test_ci_cd
    # Ekhon local e puro repo ase, ekhane kaj koro

  STEP D: Git credentials set  (push korar somoy lagbe)

    IMPORTANT: GitHub 2021 theke HTTPS push er jonno account
    PASSWORD ar neya na. LAGBE  --> Personal Access Token (PAT)

    D1. PAT banao (browser):
        1. GitHub -> Settings -> Developer settings (sesh e)
        -> Personal access tokens -> Tokens (classic)
        2. "Generate new token (classic)"
        3. Note: "test_ci_cd push"     <-- j kono naam
        4. Expiration: 30 days (practice er jonno)
        5. Scopes: "repo" tick dao (puro repo access)
        6. "Generate token" click
        7. Token ta COPY koro  (ghp_xxxxxxxxxxxx...)
           !! Eta AAR KOKHONO dekhabe NA -- ekhon-i save koro !!

    D2. Credential helper ON koro (terminal):
        git config --global credential.helper store
        #  --> prothom push er somoy username + PAT dile
        #      git seta mone rakhbe, ar porer bar ar chay na

        # (Alternative: sudhu kichukhon mone rakhe)
        git config --global credential.helper 'cache --timeout=3600'

    D3. Prothom push e ki ki dibo:
        git push origin main
        Username for 'https://github.com':  ashrafulunisoft
        Password for 'https://...':         ghp_xxxx...   <-- PAT boshabe
                                        (account password NA!)

        # "store" helper use korle ~/.git-credentials file e
        # plaintext save hoy -- practice PC e OK, shared PC e na

  STEP E (optional, password mone rakhate na chaile):
    SSH key diye-o push kora jay:
      ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N ""
      cat ~/.ssh/id_ed25519.pub
      #  --> GitHub -> Settings -> SSH and GPG keys -> New SSH key
      git remote set-url origin git@github.com:ashrafulunisoft/test_ci_cd.git
      git push origin main    # ekhon PAT o lagbe na

----------------------------------------------------------------
3.2  GENERATE SSH KEY FOR GITHUB ACTIONS
----------------------------------------------------------------
  # Generate key pair  (passphrase: empty, just press Enter)
  ssh-keygen -t ed25519 \
    -f ~/.ssh/github_actions \
    -N "" \
    -C "github-actions-deploy"

  # Authorize the public key
  cat ~/.ssh/github_actions.pub >> ~/.ssh/authorized_keys
  chmod 600 ~/.ssh/authorized_keys

  # Files created:
  #   ~/.ssh/github_actions      <-- PRIVATE  (jabe GitHub secret e)
  #   ~/.ssh/github_actions.pub  <-- PUBLIC   (VPS e thakbe)

  # Private key ta dekho (GitHub secret e lagbe):
  cat ~/.ssh/github_actions
  # --> Puro output copy koro, BEGIN theke END porjonto "Full Key Copy ---Begin *** 

  # Local test (optional, nijer VPS e-i):
  ssh -i ~/.ssh/github_actions $USER@localhost
  # Successful login hole key thik ase; "exit" diye ber hoye jaao

----------------------------------------------------------------
3.4  GITHUB ACTIONS WORKFLOW
----------------------------------------------------------------
  File: .github/workflows/deploy.yml

  name: Deploy to VPS

  on:
    push:
      branches: [main]

  jobs:
    deploy:
      runs-on: ubuntu-latest
      steps:
        - name: Checkout code
          uses: actions/checkout@v4

        - name: Copy index.html to VPS
          uses: appleboy/scp-action@v0.1.7
          with:
            host: ${{ secrets.VPS_HOST }}
            username: ${{ secrets.VPS_USER }}
            key: ${{ secrets.VPS_SSH_KEY }}
            source: index.html
            target: /var/www/html
            overwrite: true

4. BUGS HIT & FIXES  (debugging log)
========================================================================

----------------------------------------------------------------
BUG #1  -- "can't connect without a private SSH key or password"
----------------------------------------------------------------
  WHEN   : First run
  ERROR  : error: can't connect without a private SSH key or password
  CAUSE  : deploy.yml e duita alada secret name chilo:
             appleboy/ssh-action  -> ${{ secrets.VPS_SSH_KEY }}
             appleboy/scp-action  -> ${{ secrets.VPS_SSH_PRIVATE_KEY }}
           but GitHub e shudhu VPS_SSH_KEY add kora chilo.
           Second step er secret empty chil-o, ssh-action tar pore
           empty value niye fail kore.
  FIX    :
    1. Ekta secret name e consistency ano (workflow + GitHub).
    2. Naam exact same rakho.
    3. "cleanup" ssh-step ta remove koro -- scp nijei overwrite
       kore (jodi overwrite: true deoa thake).


----------------------------------------------------------------
BUG #2  -- "ssh: handshake failed: unable to authenticate"
----------------------------------------------------------------
  WHEN   : Bug #1 fix korar por
  ERROR  : ssh: handshake failed: ssh: unable to authenticate,
           attempted methods [none publickey],
           no supported methods remain
  CAUSE  : Key pair MISMATCH.
           Security discussion e ekta private key chat e share
           hoye gechilo -> VPS e NEW key generate kora holo,
           kintu GitHub e secret (VPS_SSH_KEY) ta PURANO private
           key diye-i chilo. Tai VPS er notun public key er
           sathe kono match-i holo na.
  FIX    : Puro key pair notun kore generate koro, tarpor
           GitHub secret o update koro.

            # on VPS -- full clean
            sed -i '/github-actions-deploy/d' ~/.ssh/authorized_keys
            rm -f ~/.ssh/github_actions ~/.ssh/github_actions.pub
            ssh-keygen -t ed25519 \
              -f ~/.ssh/github_actions \
              -N "" -C "github-actions-deploy"
            cat ~/.ssh/github_actions.pub >> ~/.ssh/authorized_keys
            chmod 600 ~/.ssh/authorized_keys

            # browser -- VPS_SSH_KEY secret UPDATE
            #   new `cat ~/.ssh/github_actions` output paste koro

  LESSON : Key regenerate korle GitHub secret-o SAME sitting-e
           update korte hobe. Otherwise pair out of sync thake.


----------------------------------------------------------------
BUG #3  -- "Cannot open: File exists"
----------------------------------------------------------------
  WHEN   : Bug #2 fix korar por
  ERROR  : error: tar: index.html: Cannot open: File exists
  CAUSE  : appleboy/scp-action er default overwrite: false
           mane already-existing file hole skip kore / error
           dey. /var/www/html/index.html (Apache default page)
           already chilo, tai overwrite korte parchilo na.
  FIX    : Workflow e explicit overwrite allow koro:
             overwrite: true
           (Final deploy.yml e add kora ase, dekho 3.4)


----------------------------------------------------------------
BUG #4  -- "Cannot open: Permission denied"
----------------------------------------------------------------
  WHEN   : Bug #3 fix korar por (overwrite: true add kore push)
  ERROR  : error: tar: index.html: Cannot open: Permission denied
  CAUSE  : /var/www/html directory-tai root er owned chilo
           (Apache er default). ai_root er write permission
           chilo na. Overwrite korte parbe na even after
           overwrite: true.
  FIX    : VPS e:
             sudo chown -R ai_root:ai_root /var/www/html
             rm -f /var/www/html/index.html
           (Directory er ownership niye ai_root nicher file
           gulo delete / overwrite korte parbe.)

  LESSON : Deploy user ke target directory-r owner hote hobe
           ba write permission thakte hobe. Eta ke "deploy
           user" pattern bole.

7. SECURITY LESSONS LEARNED
========================================================================

  1. PRIVATE KEY NEVER SHARE KORO
     Chat, screenshot, public repo, ba even private repo
     jekhane oi key onno jaigaeo use hoche -- lekhao na.
     Leak hole assume koro COMPROMISED -- key regenerate
     koro ar joto system e chilo shob jaigae update koro.

  2. EK SECRET NAME, EVERYWHERE
     Workflow e ${{ secrets.X }} ar GitHub Settings e name
     EXACTLY match korte hobe. Case-sensitive.

  3. DEPLOY USER MINIMAL PRIVILEGE
     Practice e root/ai_root chole geleo, real production e
     alada "deploy" user banano better -- sudo chara, shudhu
     /var/www/html e write access. Apache www-data hisebe
     cholbe, deploy alada thakbe.

  4. PUBLIC/PRIVATE PAIR SYNC
     VPS e key rotate korle SAME sitting-e GitHub secret
     o update korte hobe. Nahole deploy suddenly break hobe
     ar karon bujhte somoy lagbe.
